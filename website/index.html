What is MOAH?

MOAH is an experimental coding agent harness built around dynamic tool loading.

Instead of exposing every available capability on every request, MOAH keeps a larger tool library outside the active context and selects what the agent needs for the task at hand.

Dynamic tool loading

Tools enter the active context only when they’re useful.

Tool routing

A lightweight router selects capabilities for each task.

On-demand tool library

Keep more capabilities available without exposing them all at once.
