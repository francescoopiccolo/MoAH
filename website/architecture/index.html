MOAH separates the tools an agent can use from the tools currently exposed to the model. Its runtime, derived from Pi, ships inside the npm package; moah starts the harness directly.

Four states.

Known to router

The tool exists and can be selected.

Loaded in memory

The tool is ready without being exposed to the model.

Active in context

The model can see and invoke the tool.

Executing

The tool is currently being used.

Three loading strategies.

Resident

Keep frequently used tools ready.

On demand

Load a tool when the router selects it.

Prefetch

Predict the next useful tool and load it ahead of time.
